OpenGL Graphics

This project presents three distinct 3D scenes developed with OpenGL, each showcasing specialized rendering techniques. The first scene features a heightmap-based terrain system implementing multi-texturing for surface variation, with procedurally placed trees dynamically positioned according to terrain elevation and normal vectors. The second scene demonstrates advanced lighting systems through a robotic character with fixed-follow camera perspective; this configuration includes a dynamic spotlight emitter originating from the robot that casts real-time shadows onto forward-facing geometry. The third scene returns to heightmap terrain generation to create a volcanic mountain landscape, featuring a GPU-accelerated particle system for volcanic effects.

Physics engine

This project demonstrates a series of technical scenes showcasing a custom-built physics engine developed natively in C++. Each scene implements sophisticated collision detection algorithms and physically accurate response systems across diverse object types. The engine efficiently handles real-time physics simulations, calculating dynamic interactions between objects with varying properties while maintaining stable collision resolutions and realistic behavioral feedback.
